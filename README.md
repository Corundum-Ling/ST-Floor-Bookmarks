# 楼层书签 (Floor Bookmarks)

SillyTavern 插件：收藏指定楼层的聊天记录，支持回看、跳转、导出、复制，可以给收藏加标题和分类标签，也可以直接在正文里划重点。

---

## 功能

| 功能 | 说明 |
|---|---|
| **收藏楼层** | 每条消息旁显示书签图标，点击收藏 / 取消 |
| **按版本区分** | 同层不同 swipe 版本是独立收藏，标注「版本N」 |
| **全局收藏夹** | 跨角色、跨聊天可见；按「角色卡 → 聊天」两级分组 |
| **标题** | 给单条收藏起名（最长 60 字），标题替代正文成为条目的主行 |
| **分类标签** | 每条最多 5 个标签，单个最长 20 字；从已有标签里点选，也可自己输入 |
| **搜索筛选** | 按内容 / **标题** / **标签** / 发送者 / 聊天名 / 角色名搜索；全部 / 当前聊天 / 其他聊天 |
| **查看全文** | 弹窗显示完整消息（保留原始排版），点条目正文或 👁 触发 |
| **跳转定位** | 自动加载历史消息并滚动到目标楼层，闪烁高亮 |
| **前往聊天** | 收藏属于别的聊天时，点跳转自动切过去再定位，并把该层切回你收藏时的那个版本；聊天头右侧的箭头可直接切到该聊天 |
| **置顶排序** | 当前角色卡的收藏置顶，组内当前聊天置顶，其余按收藏数 / 最近收藏排 |
| **分组折叠** | 角色卡和聊天两级标题都能点一下收起，收藏多的聊天先折起来 |
| **单条导出** | 导出为 Markdown 文件，含元数据表格（标题与标签一并写入） |
| **一键复制** | 复制单条收藏的内容，点按钮后选 Markdown 或纯文本 |
| **划重点** | 在查看器里选中正文任意片段，加四色底纹 / 四色字 / 下划线 / 波浪线 |
| **面板可拖动/缩放** | 支持鼠标与触屏，位置尺寸持久化 |

## 安装

### 方式一：通过 ST 扩展面板安装（推荐）

SillyTavern → 扩展 → 安装扩展，填入本仓库 URL。

### 方式二：手动安装

把本目录复制到 SillyTavern 的扩展目录：

```
<SillyTavern>/data/default-user/extensions/ST-FloorBookmarks/
```

Windows 命令：

```cmd
xcopy /E /I /Y "本目录路径" "<SillyTavern>\data\default-user\extensions\ST-FloorBookmarks"
```

两种方式安装后都**刷新页面**（F5）即可，无需重启服务端。

## 使用

1. 打开任意聊天
2. 消息右下角出现**书签图标**（未收藏时半透明）
3. 点击图标 → 图标变金色 = 已收藏
4. 点击**右上角工具栏**里的「**楼层书签**」打开收藏夹面板，或从**扩展菜单**里点击「楼层书签」打开

### 面板按钮说明

鼠标悬停在收藏条目上，右上角出现六个按钮：

| 图标 | 功能 | hover 颜色 |
|---|---|---|
| ✎ | 编辑标题与标签 | 紫 |
| ⧉ | 复制正文（选 Markdown / 纯文本） | 青 |
| ⤓ | 导出为 Markdown | 绿 |
| 👁 | 查看完整消息 | 蓝 |
| → | 跳转到该层 | 金 |
| 🗑 | 删除这条收藏 | 红 |

点条目**正文**或**标题**等同于「查看完整消息」。

### 标题与标签

编辑入口在「查看完整消息」弹窗里——点条目正文、标题，或右上角的 ✎ 按钮打开。

- **标题**：在弹窗顶部输入框填写，回车或点别处即保存。留空则条目回退为显示正文摘要。
- **标签**：在标签框里输入后按 `Enter` 或逗号添加，也可以直接点下方「已有」里列出的历史标签（一条收藏的标签用久了会形成固定选项，避免同一个意思打成好几种写法）。
- 点标签上的 `×` 移除；标签框为空时按 `Backspace` 可删掉最后一个。
- 标签会显示在条目上，并**参与搜索**：在面板搜索框里打标签名即可筛出所有打了该标签的收藏。
- 导出的 Markdown 会包含标题（作为一级标题的一部分和元数据表的一栏）和标签。

数据全部写在 `fb-index.json` 里，老版本索引没有这两个字段也能正常读取（自动补空），升级不会丢收藏。

### 一键复制

点条目上的 ⧉ 按钮，弹出两个选项：

- **复制 Markdown**：保留段落、粗体 / 斜体 / 行内代码，图片保留为 `![说明](地址)`
- **复制纯文本**：只留文字，图片退化为它的说明文字

局域网用 http 访问时浏览器不提供 `navigator.clipboard`，插件会自动退回 `textarea + execCommand` 的旧方案，仍然可用。

### 划重点

在「查看完整消息」弹窗里**选中正文任意一段**，松手后选区上方浮出一排色块：

| 上行 | 四色底纹（黄 / 绿 / 蓝 / 粉） + 四色字（红 / 橙 / 蓝 / 绿，按钮上是 A） |
|---|---|
| **下行** | 下划线 / 波浪线 / 清除 |

- 三种样式族——**底纹、字色、线型**——各自独立，可以叠在同一段上（例如黄底 + 红字 + 下划线）。同一族内部互斥：在同一段上换色等于替换，不会叠成两层。
- 想取消时，**再点一次同样的那个按钮**即可；点「清除」则把选区上的三族样式一起抹掉。
- 标注跟着收藏走：存在同一条 `fb-<uuid>.json` 里，不占索引。关掉弹窗再打开，标注还在。
- 手机端长按选词同样会浮出色块。

标注记的是**正文字符偏移量**（相对纯文本，不含 HTML 标签），所以原消息里的排版（粗体、代码块、换行）不会影响定位。

### 快捷键

- `ESC`：关闭查看器 / 关闭面板

## 数据存储

收藏数据存放在**服务端文件**，不占用 `settings.json`：

```
<SillyTavern>/data/default-user/user/files/
├── fb-index.json          # 轻量索引（元数据、标题、标签）
└── fb-<uuid>.json         # 每条收藏的正文（HTML 快照 + 划重点标注）
```

**索引与正文分离**：删除单条只需删除一个文件，不必重写全量。

数据存放在服务端 `user/files/` 目录下，可以随 ST 的 `data` 目录一起备份。

### 快照机制

收藏时保存的是**消息 HTML 快照**，而非楼层索引引用 —— 因为删除中间楼层会导致 `mesid` 整体前移，只存索引必然错位。

快照在写入前经 DOMPurify 清洗（移除 `<script>`、`on*` 事件属性、危险协议）。

## 兼容性

| 项 | 要求 |
|---|---|
| SillyTavern | 1.12+（在 1.18.0 上开发验证） |
| 浏览器 | Chrome / Edge / Firefox 现代版本；移动端浏览器 |
| 依赖 | 无。DOMPurify 不可用时自动降级为纯文本快照 |

### 长聊天优化插件

已测试与 [ST-BaiBai-Tools](https://github.com/StageDog/tavern_resource) 的长聊天 DOM 渲染优化功能共存，按钮注入正常。

### 虚拟化渲染

SillyTavern 打开长聊天时只渲染最后 `chat_truncation` 条消息（可配置，默认约 20 层），更早的楼层需要点击「Show more messages」才会加载。

本插件监听 `MORE_MESSAGES_LOADED` 事件，在每次回填后重新注入按钮。

## 已知限制

1. **跳转到极早楼层需要逐批加载**。目标层距离当前渲染范围很远时，插件会反复触发「Show more messages」，可能需要数秒。单次跳转最多点击 60 批，超出则提示失败。

2. **只能在同一位角色的聊天之间切换**。分支聊天（`- Branch #N`）属于同一张角色卡，可以自动切过去并定位；但跨角色卡的收藏仍会提示先切到那张角色卡，群聊的收藏也不支持前往。切聊天会替换当前对话（ST 会先存盘），但输入框里还没发出去的文字会丢。

3. **楼层前移导致定位偏移**。如果在收藏点之前删除了楼层，跳转会定位到 `mesid` 相同但内容不同的消息。

4. **导出不含图片数据**。HTML 快照中的 base64 内嵌图片在转为 Markdown 时只保留占位标记。

5. **存储空间无上限提示**。收藏条目过多时会持续占用磁盘，无自动清理。

6. **标签不能批量重命名**。改一个标签要逐条打开收藏修改；也没有「删除某标签」的全量操作。标签是自由文本，插件不做全局标签管理。

7. **划重点是给「快照」做的**。标注记的是字符偏移量，而快照在收藏那一刻就固定了，所以标注永远对得上。但如果同一条消息后来重 roll / 编辑过，新版本是另一条收藏，旧收藏上的标注不会跟着变。

8. **跳转会把该层切到收藏时的版本**。切版本走的是酒馆自己的 swipe 机制，会写进聊天文件——和手动划一下是一个效果，看完想回原来那版再划回去即可。
